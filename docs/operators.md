|     1      |     Left      | function `()`, array `[]`, `.` |

|     2      |     Left      |    prefix `++`, prefix `--`    |
|     3      |     Left      |          `*` `/` `%`           |
|     4      |     Left      |            `+` `-`             |
|     5      |     Left      |       `<=` `<` `>` `>=`        |
|     6      |     Left      |           `!=` `==`            |
|     7      |     Left      |             `and`              |
|     8      |     Left      |              `or`              |
|     9      |     None      |  `=` `+=` `-=` `%=` `/=` `*=`  |
