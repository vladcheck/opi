# EBNF Cheat Sheet

- `::=` means "is defined as" (sometimes written as `->`).
- `|` means "or" (alternation).
- `[ ... ]` means "optional" (zero or one time).
- `{ ... }` means "zero or more times" (the repitition).
- `( ... )` is used for grouping.
- `"..."` or `'...'` represents a literal token (like `"+"` or `"func"`).
